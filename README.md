# Student Career Recommendation System Web Version

This version runs in any browser and requires no Python installation.

## Run locally

Open `index.html` by double-clicking it.

## Publish free on GitHub Pages

1. Sign in at https://github.com.
2. Create a new public repository named `student-career-recommendation`.
3. Upload `index.html`, `style.css`, `script.js`, and this README file.
4. In the repository open **Settings → Pages**.
5. Select **Deploy from a branch**, choose branch **main**, folder **/(root)**, then Save.
6. GitHub will show a public URL in the Pages section after a few minutes.

Career records are saved only in the visitor's browser using local storage.
